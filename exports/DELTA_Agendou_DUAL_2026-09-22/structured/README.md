# README - Exportacao DUAL do DELTA Agendou

Esta pasta contem a exportacao estruturada do DELTA usado para transformar o roadmap do Agendou em um pacote executavel de MVP para um SaaS de agendamento.

## Como usar

1. Leia `RESUME.md` para entender o ponto de retomada.
2. Use `03-definicao.md` e `04-decisoes.md` para validar intencao, escopo e decisoes.
3. Use `05-artefatos.md` para localizar os arquivos gerados no workspace.
4. Use `06-backlog-e-plano.md` para iniciar a execucao.
5. Use `10-retomada.md` como prompt para continuar com outro agente ou nova sessao.

## Conteudo DUAL

- **Structured:** arquivos Markdown separados por contexto nesta pasta.
- **Monolith:** arquivo unico `MONOLITH.md` na raiz da exportacao.

## Limite importante

A exportacao preserva o contexto disponivel nesta conversa. Ela nao inclui o conteudo integral de `SDD_SaaS_Agendamento.md`, pois esse arquivo nao estava presente no workspace; o roadmap informa que ele foi a base original.
